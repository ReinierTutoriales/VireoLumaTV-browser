# VireoLumaTV 2.0.22

Correcciones de navegación y descargas sobre la interfaz Compose para TV.

## Novedades y correcciones

- **Atrás:** ajuste de la salida al launcher desde Inicio, conservando la protección al salir de pantalla completa.
- **Descargas:** el menú vuelve a mostrar las transferencias activas y su cantidad en la descripción accesible.
- **Historial y Descargas:** tipos de contenido explícitos para la reutilización de elementos en Compose.
- **Icono de TV:** recursos ajustados y conversión de PNG a WebP.
- **Mantenimiento:** retirada de BrowserControls y textos sin uso, correcciones de lint Compose, Rust fijado en 1.99.1 y perfiles de arranque regenerados para generic/foss/google.

## Validación

Los cambios integrados pasaron pruebas automáticas, compilaciones y arranques en emuladores API 24, 28, 34 y 37. La validación física de mando, teclado, vídeo y memoria en TV sigue pendiente; no se afirma una mejora de rendimiento en hardware.

## Instalación

Disponible para Android 7.0 o superior. Instala el APK compatible sobre tu versión actual para conservar tus datos, favoritos y ajustes.
