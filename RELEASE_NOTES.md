# VireoLumaTV 2.0.21

Interfaz del navegador renovada con Compose para TV y navegación con mando.

## Novedades y correcciones

- **Interfaz para TV:** cápsula superior, pestañas, Ajustes, Inicio, Favoritos, Historial, Descargas, sugerencias, menús y diálogos en Compose para TV.
- **Mando y foco:** controles de pestañas separados, foco visible y acciones ejecutadas al activar los controles. En Ajustes, las pestañas cambian al pulsar OK y los textos se editan en un diálogo.
- **Inicio:** edición de accesos con mover, editar y quitar, conservando el orden guardado y el almacenamiento separado del modo privado.
- **Puntero:** movimiento diagonal normalizado y corrección del deslizador para poder volver al valor inicial con el puntero después de cambiarlo con el mando.
- **Idiomas:** selección con las API de Android y migración del idioma guardado por AppCompat.
- **Mantenimiento:** iconos tipados centralizados, retirada de AppCompat, Fragment, RecyclerView y recursos sustituidos; actualización de dependencias y perfiles de referencia regenerados.

## Validación

Los cambios integrados pasaron pruebas automáticas, compilaciones y arranques en emuladores API 24, 28, 34 y 37. La validación física de mando, teclado, vídeo y memoria en TV sigue pendiente; no se afirma una mejora de rendimiento en hardware.

## Instalación

Disponible para Android 7.0 o superior. Instala el APK compatible sobre tu versión actual para conservar tus datos, favoritos y ajustes.
