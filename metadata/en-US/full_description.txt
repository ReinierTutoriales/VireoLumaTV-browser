Web browser optimised to use with TV remote.
Features:
- working with TV remote
- tabs and bookmarks support
- voice search support
- switch user agent support
- use Android builtin web rendering engine (WebKit/Blink based)
- built-in download manager
- browsing history
- shortcuts
Based on the source code of TV Bro by Fedir Tsapana: https://github.com/truefedex/tv-bro . VireoLumaTV is maintained independently.
